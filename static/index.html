软链接方式要求 B 与 A 在同一目录（这样容器内挂载该目录后链接一定能解析）；跨目录请选「同步副本」。A 不在可写根下时需把宿主机根目录挂到 /host 才能读取。B 已存在且是真实文件时一律拒绝覆盖，不会误删数据。

镜像更新

比对远端 digest，可只拉取镜像，也可拉取后按原配置重建使用该镜像的容器

两种模式：①「更新选中」只拉取镜像、不重建容器，运行中的容器仍用旧镜像；②「更新并重建」拉取后按原配置重建使用该镜像的容器，先备份、保留端口/环境变量/卷/网络/标签，健康检查不通过自动回退，会短暂中断服务。只有检测到可更新版本才显示这两个按钮。

版本备份与回退
更新后健康检查 v6.0 新增
容器重建后先确认服务真的起来了：默认只校验「运行中」，也可改为 HTTP / TCP 探测。探测不通过且开启自动回退时，面板会立刻恢复到更新前的版本并推送通知。

HTTP 探测把 4xx（例如要求登录）视为「服务有响应」，只有连接失败、超时和 5xx 才算异常；没有端口映射时自动降级为运行状态检查。
